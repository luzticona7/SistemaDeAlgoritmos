Ayuda - Sistema de Ordenamiento

¿Qué es este sistema?

Este es un sistema interactivo para visualizar algoritmos de ordenamiento en tiempo real. Puedes ver cómo diferentes algoritmos ordenan datos representados como burbujas animadas.

Cómo usar la aplicación

  • Generar Aleatorio: Crea un array con valores aleatorios
  • Entrada Manual: Permite ingresar el tamaño y valores específicos del array
  • Importar JSON: Carga un array desde un archivo JSON o texto
  • Exportar JSON: Muestra el array actual en formato JSON
  • Descargar JSON: Guarda el array actual en un archivo JSON
  • Capturar Imagen: Descarga una imagen del algoritmo ordenado
  • Iniciar Ordenamiento: Comienza la visualización del algoritmo
  • Detener: Pausa la visualización en curso

Algoritmos disponibles

  • Shell Sort: Ordena elementos separados por brechas que se reducen progresivamente
  • Merge Sort: Divide y vencerás dividiendo el array en mitades, ordenándolas y fusionándolas
  • Selection Sort: Encuentra el elemento mínimo/máximo y lo coloca en su posición correcta
  • Insertion Sort: Construye el array ordenado insertando un elemento a la vez en su posición correcta

Formatos de entrada

Entrada Manual: Puede generar valores aleatorios o agregar valores uno por uno

Importar JSON: El formato debe ser: {"array": [valores], "size": tamaño}. El tamaño debe coincidir con la longitud del array.
