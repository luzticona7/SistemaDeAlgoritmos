Ayuda / Tutorial
Cómo usar la página
  1. Importar .fis: pulsa el botón Importar .fis y selecciona tu archivo (ASCII exportado desde MATLAB u otro editor FIS).
  2. Explorar Inputs: en el panel derecho verás cada entrada con su gráfica de funciones de pertenencia. Haz click en la gráfica o mueve el slider para mover el puntero.
  3. Evaluar: pulsa Evaluar para recalcular las salidas (valor crisp + categoría más activa).
  4. Reglas: edita las reglas mediante la tabla friendly (selects por cada entrada y por la salida). Pulsa Guardar reglas para aplicar los cambios.
  5. Mostrar 3D: pulsa Mostrar 3D para ver la superficie (si tu FIS tiene 2 o 3 entradas). Si tiene 3 entradas, ajusta el slider "Valor fijo — 3ª entrada" para elegir el corte.
  6. Exportar .fis: descarga un archivo .fis reconstruido desde la estructura actual (incluye reglas guardadas).
Breve teoría: ¿qué es la lógica difusa?

La lógica difusa (fuzzy logic) extiende la lógica booleana para modelar conocimiento impreciso o vago. En lugar de asignar valores '0' o '1' exclusivamente, las variables difusas pueden tener grados de pertenencia entre 0 y 1.

Conceptos clave
  • Funciones de pertenencia (MF): definen cuánto pertenece un valor a un conjunto difuso (por ejemplo, "frío", "templado", "caliente"). Pueden ser triangular, trapezoidal, gaussiana, etc.
  • Reglas difusas: expresiones tipo IF entrada1 IS alto AND entrada2 IS bajo THEN salida IS media. Las condiciones (antecedentes) se evalúan en grados y se combinan con operadores (AND/OR).
  • Inferencia (Mamdani): se calcula la activación de cada regla (por ejemplo AND = min), se aplica la implicación (clipping) y se agregan todas las contribuciones (max).
  • Defuzzificación: convierte la salida difusa agregada a un valor crisp (numérico). En este visor usamos el método centroid (centroide) que es el más común.
Por qué fija la 3ª entrada en 3D

Un sistema con 3 entradas define una función de 4 dimensiones (x1,x2,x3 → y). Para visualizar en 3D elegimos dos entradas para X/Y y fijamos la tercera en un valor (corte). Cambiando ese valor veremos cómo cambia la superficie.

Consejos
  • Si tu archivo .fis tiene sintaxis inusual, revisa su estructura antes de importarlo.
  • Si las reglas no producen la salida esperada, revisa los índices de MFs en la tabla friendly (0 = any, 1..N corresponden a los MFs).
