Ayuda - Algoritmo de Transporte Mejorado

Algoritmos Implementados

  • Minimización: Algoritmo Northwest (Esquina Noroeste) - Encuentra una solución básica factible comenzando desde la esquina superior izquierda
  • Maximización: Algoritmo de Máximo Beneficio - Prioriza las celdas con valores más altos para maximizar el beneficio total

Cómo usar esta herramienta

  • Configurar el problema: Define el número de orígenes y destinos
  • Seleccionar modo: Elige entre Minimización o Maximización
  • Ingresar datos: Completa la matriz de costos, ofertas y demandas
  • Equilibrar: Asegúrate de que oferta total = demanda total
  • Ejecutar: Usa "Ejecutar Algoritmo" para solución automática o "Paso a paso" para ver el proceso
  • Ver resultados: Revisa las iteraciones y la solución final
