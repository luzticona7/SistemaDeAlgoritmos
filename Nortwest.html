Ayuda - Algoritmo Northwest

¿Qué es el Algoritmo Northwest?

El algoritmo de la Esquina Noroeste (Northwest Corner Method) es un método para encontrar una solución básica factible inicial en problemas de transporte. Comienza asignando la máxima cantidad posible a la celda superior izquierda (noroeste) y avanza hacia la derecha y abajo.

Cómo usar esta herramienta

  • Configurar el problema: Define el número de orígenes y destinos
  • Ingresar datos: Completa la matriz de costos, ofertas y demandas
  • Equilibrar: Asegúrate de que oferta total = demanda total
  • Ejecutar: Usa "Ejecutar NW" para solución automática o "Paso a paso" para ver el proceso
  • Ver resultados: Revisa las iteraciones y la solución final

Funcionalidades de Importar/Exportar

  • Exportar: Guarda el problema actual como archivo JSON
  • Importar: Carga un problema previamente guardado
  • Captura: Descarga una imagen del estado actual

Formato de archivo JSON

Los archivos de exportación siguen este formato:

{
  "m": 3,
  "n": 3,
  "cost": [[...], [...], [...]],
  "supply": [...],
  "demand": [...]
}

Consejos

  • El algoritmo Northwest proporciona una solución básica pero no necesariamente óptima
  • Para obtener soluciones óptimas, considera usar métodos como el de Vogel o MODI
  • Guarda tus problemas frecuentes para cargarlos rápidamente
  • Usa capturas para documentar tus resultados
