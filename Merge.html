Ayuda - Merge Sort Visualizer

¿Qué es Merge Sort?

Merge Sort es un algoritmo de ordenamiento eficiente que utiliza el enfoque "divide y vencerás". Divide el array en mitades, ordena cada mitad recursivamente y luego las combina.

Cómo usar la aplicación

  • Generar Aleatorio: Crea un array con valores aleatorios
  • Entrada Manual: Permite ingresar el tamaño y valores específicos del array
  • Importar JSON: Carga un array desde un archivo JSON o texto
  • Exportar JSON: Muestra el array actual en formato JSON
  • Descargar JSON: Guarda el array actual en un archivo JSON
  • Capturar Imagen: Descarga una imagen del algoritmo ordenado con subarrays
  • Iniciar Merge Sort: Comienza la visualización del algoritmo
  • Detener: Pausa la visualización en curso

Formatos de entrada

Entrada Manual: Puede generar valores aleatorios o agregar valores uno por uno

Importar JSON: El formato debe ser: {"array": [valores], "size": tamaño}. El tamaño debe coincidir con la longitud del array.
